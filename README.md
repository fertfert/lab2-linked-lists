# Лабораторная работа №2. Связанные списки

Python 3.10+. Выполнены бронза, серебро и золото по слайдам и раздатке: односвязный и двусвязный списки, сравнение с массивом, графики и сравнительная таблица.

## Запуск

```bash
python demo.py
python -m unittest discover -s tests -v
python -m pip install -r requirements.txt
python benchmark.py
```

Matplotlib нужен только для экспериментов. Все структуры и тесты работают со стандартной библиотекой. Готовые графики и CSV находятся в `results/`, методика, результаты, сравнительная таблица и выводы — в [REPORT.md](REPORT.md).

Для короткого запуска эксперимента:

```bash
python benchmark.py --sizes 1000 5000 --repeats 3
```

Повторный запуск заменяет результаты и отчёт данными нового эксперимента.

## Реализация

| Файл | Содержание |
|---|---|
| `singly_linked_list.py` | `Node`, `SinglyLinkedList`: prepend, append без tail, find, delete, get, len, str |
| `doubly_linked_list.py` | `DNode`, `DoublyLinkedList`: prepend, append с tail, find, delete, get, reverse, len, str |
| `static_array.py`, `dynamic_array.py`, `dynamic_array_gold.py` | Копии проверенных массивов из [ЛР1](https://github.com/fertfert/lab1-arrays), исходный коммит `91c8bcd` |
| `tests/` | Проверка контрактов, граничных случаев и структурных инвариантов |
| `benchmark.py` | Замеры prepend и get(n//2) при размерах до 100 000, графики и отчёт |

Встроенные контейнеры не используются как хранилище списков: только узлы и ссылки. `list` в тестах служит эталоном, контейнеры в эксперименте хранят результаты измерений. Копии массивов позволяют запускать эту работу без клонирования первого репозитория.

## Поведение методов

- `find(data)` возвращает первый **узел**, а не индекс, либо `None`.
- `delete(data)` удаляет только первое совпадение и возвращает `None`; отсутствующее значение ничего не меняет.
- `get(index)` возвращает значение; допускаются целые индексы от 0 до `len-1`. Отрицательные и выходящие за размер индексы вызывают `IndexError`, нецелые — `TypeError`.
- `reverse()` меняет двусвязный список на месте и возвращает `None`.
- Пустой список печатается как `None`; непустой — `10 -> 20 -> None` либо `10 <-> 20 <-> None`.
- Односвязный список намеренно не хранит tail: append имеет O(n), как в бронзовом задании. get добавлен для золотого уровня.
- Для корректной работы структуры не следует вручную изменять ссылки возвращённого узла.

Замеры вставки выполняются сериями по 50 операций на заполненной структуре, доступа — по 200. На графиках показано время одной операции. Точная методика и отличие от заполнения пустой структуры n вставками описаны в отчёте.
